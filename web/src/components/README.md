# Components

## Overview
Reusable UI and feature components of the Huellicam web application organized by domain and design-system layer.

## Subdirectories & Boundaries
- Admin: [./admin/README.md](./admin/README.md) - Administrative executive unit-economics metrics, white-label pricing editor, and runtime feature-flag kill-switch modal.
- Call: [./call/README.md](./call/README.md) - LiveKit teleconsultation room wrapper, pre-join audio/video modal, global incoming call listener, and delivery checkmarks.
- Chat: [./chat/README.md](./chat/README.md) - Clinical consultation chat thread supporting text, image thumbnails, document cards, quick replies, and file uploads.
- Common: [./common/README.md](./common/README.md) - Branding primitives, password change modal, cookie consent banner, error boundary, offline banner, scoped CSS injector, and session termination modal.
- Dashboard: [./dashboard/README.md](./dashboard/README.md) - Clinical triage intake form, printable pet medical dossier modal, and veterinary patient profile drawer.
- Icons: [./icons/README.md](./icons/README.md) - Veterinary species-specific SVG icons (`DogIcon`, `CatIcon`, `RabbitIcon`, `SpeciesIcon`).
- Legal: [./legal/README.md](./legal/README.md) - Shared layout wrapper for public terms, privacy, cookie, and refund policy pages.
- Multimedia: [./multimedia/README.md](./multimedia/README.md) - Multimedia shared UI primitives, SVG icon registry, and history-based navigation helpers.
- UI: [./ui/README.md](./ui/README.md) - Atomic and composite design-system components (buttons, inputs, badges, modals, prescriptions, reviews, triage selector, skeletons, and mascot).
